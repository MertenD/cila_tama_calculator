## Typische Dateistruktur im nrrd-Ordner

Jeder `nrrd/` Ordner enthält typischerweise:

### DICOM-Unterordner
```
1.3.12.2.1107.5.1.4.xxxxx.xxxxx/  (DICOM-UID als Ordnername)
```

### Segmentierungsdateien (.nrrd)

#### Anatomische Strukturen:
- `F01 Aorta_generic_primary_primary_*.nrrd` - Aorta-Segmentierung
- `F02 Vena_generic_primary_primary_*.nrrd` - Venen-Segmentierung
- `F03 M_ quadratus lumborum rechts_generic_primary_primary_*.nrrd` - Quadratus-Muskel rechts
- `F04 M_ erector spinae rechts_generic_primary_primary_*.nrrd` - Erector-spinae-Muskel rechts
- `F05 M_ psoas major rechts_generic_primary_primary_*.nrrd` - Psoas-Muskel rechts
- `F06 Vert_generic_primary_primary_*.nrrd` - Wirbelsäulen-Segmentierung
- `F07 Visc_generic_primary_primary_*.nrrd` - Viszerale Strukturen
- `F08 Musc_generic_primary_primary_*.nrrd` - Muskulatur gesamt

### Begleitdateien

Für jede .nrrd Datei existieren:
- `.json` Datei - Metadaten zur Segmentierung
- `.pf` Datei - Weitere Verarbeitungsinformationen (für einige Dateien)

### Vom Skript generierte Dateien

Nach der Verarbeitung durch `SkriptNatalija.py` werden zusätzlich erstellt:
- `original.nrrd` - Original-DICOM-Serie
- `fusedTama_Review.seg.nrrd` - Fusionierte TAMA-Segmentierung
- `psoas_Review.seg.nrrd` - Review Psoas-Segmentierung
- `quad_Review.seg.nrrd` - Review Quadratus-Segmentierung
- `erec_Review.seg.nrrd` - Review Erector-Segmentierung
- `vert_Review.seg.nrrd` - Review Wirbel-Segmentierung
- `filTama_Review.nrrd` - Gefilterte TAMA
- `psoas_Review_fil.nrrd` - Gefilterte Psoas
- `quads_Review_fil.nrrd` - Gefilterte Quadratus
- `erec_Review_fil.nrrd` - Gefilterte Erector
- `quadErec_Review_fil.nrrd` - Gefilterte kombinierte Quad+Erector
